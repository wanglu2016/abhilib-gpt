# 命题译读

把一句毗昙中文转成一个可复核的解释。打开研究页，左边选书中原句，右边看从公式读回来的中文。可以改句、补语境、比较不同读法、下载完整的 Lean 文件，或在本机保存审读意见。[在线工具](https://wanglu2016.github.io/abhilib-gpt/translate/)

## 用什么检验它

先打开第 3 例「有業道非業」。删掉「有」再按「轉成公式」。原句只需举出一个业道而非业的例子。改句要求每一个业道都非业。如果在一个测试情形中有两例业道，一例是业、另一例非业，原句成立，改句不成立。

再试「阿那含只成就無漏初靜慮」。工具会要求限定「只」。设想检验用的一个人位，兼成就有漏、无漏初静虑，未成就其余三地的无漏静虑。固定初静虑而排除有漏，这个人位违背句意。固定无漏而排除另外三地，这个人位符合句意。这个假设情形只用来区分两种解释。可在页面比较两种候选反译和公式。

第 9 例节取四句中的一格。书页给出了定地和问答结构，初次打开时页面会把这两项列入上下文。「清除上下文」后，两项都须重新决定。如果取「列举一格」，公式接受一个人位返回一个判断。取「至少有一个这样的时位」，才产生一个存在命题。其他例句直接从输入解析。每例的出处、书页和是否节引都在[样本目录](cases.mjs)。

## 公式里的对象

| 记号或字段 | 所表示的对象或关系 |
| --- | --- |
| `D` | 研究范围内、容许情形中的法的个例。按一生中实际出现过的法取值，会改变「能」的含义。 |
| `S` | 一位有情在某一时位。用同一个变元表达条件前后的人与时间相同。 |
| `binding`、`born` | 分别给出法的系属与有情的生地。法的系属可以为空。 |
| `possesses`、`manifestNow`、`acquiresNow` | 成就、现前、得分别建模。「成就甲类法」展开为在同一人位至少成就该类的一法。 |
| `immediatelyPrecedes a b` | 在同一相续中许可前念 a 无间生后念 b。类与类之间能相生，展开为存在这样的一对。 |
| `∀`、`∃`、`¬`、`→`、`↔` | 分别表示每一个、至少一个、否定、推出、双向推出。 |
| `Prop` 与 `S → Prop` | 前者是一项判断。后者给出判断条件，代入某个人位后才得到判断。 |

词表给出类型、字形、释义和 Lean 展开式。例如「无记」展开为有覆无记或无覆无记，「上界有情」展开为生色界或生无色界。「业」「业道」等仍是要由研究者解释的基本分类。模型保留二者的外延供比较。这里尚未给出全部基本分类的教理判准，也没有把一个读法自动登记为已证定理。

## 覆盖范围和扩展

目前能组合的表达包括泛称、存在、否定、范围明确的并列、两类等同、必要与充分条件、成就及其例外、可能或禁止的无间相生、三性分别有例，以及有语境的修定省略句。简繁文字共用同一词表。整句须能解析。新词、未支持句式、否定中范围不清的并列都有显式反馈。系统仅能提示已识别的歧义，成功解析的句子仍可能误读。

从新书页增加例句时，先试自由输入。如果已有词义和构式足够，只需把书页、引句、上下文录入 `cases.mjs`。新概念进入 `vocabulary.mjs`，需要新的对象或基本关系时扩展 `model.mjs`。新构式在 `grammar.mjs` 中组合原有量词、谓词和关系；同时增加改变一处措辞就改变意思的测试。`logic.mjs` 检查变量和类型，从树生成三种输出。解析器不读取样本表、编号、页码或预写的目标公式。

## 本地使用

在仓库根目录运行，浏览器打开终端所示地址的 `/translate/` 路径。模块、样本和转换都在本机，查原书和访问 GitHub 需要联网。

```sh
python3 -m http.server 8000 --directory docs
```

命令行使用 Node.js 18 以上版本；最后两行另需仓库锁定的 Lean 4.19.0 在 PATH 中。

```sh
node tools/translate.mjs '有些业道不是业'
node tools/translate.mjs '阿那含只成就无漏初静虑' only=levels --lean
node tools/translate.mjs --demo-lean > Readings.lean
lean Readings.lean
node tools/test-translate.mjs --lean
```

常规的 `python3 tools/build.py --check` 也运行译读测试。在小模型中比较两种读法，再把十个例子编译为 Lean 定义，检查代表性公式能否作为推理的前提使用。机器可以检查公式的类型与推理是否有效；「原文在这里恰好意指这条公式」留给审读。批注可导出为 JSON，包含送审原句、语境选择与公式。

# AbhiLib 毗昙库

**一个可以复算的有部阿毗达磨形式化研究初版。** 打开研究页，可以从一句原文进入 Lean 命题，查看证明所需条件，再撤去一项条件，检查是否出现反例。

[进入研究工作台](https://wanglu2016.github.io/abhilib-gpt/) · [逐步读王路的证明](https://wanglu2016.github.io/abhilib-gpt/#S01) · [前提与反例实验](https://wanglu2016.github.io/abhilib-gpt/#lab)

## 从一句中文开始

[打开独立的命题译读工具](https://wanglu2016.github.io/abhilib-gpt/translate/) · [输入自己的命题](https://wanglu2016.github.io/abhilib-gpt/translate/#new)

左栏十例摘自王路《俱舍九题》，每条可打开电子书对应页。输入框接受简体、繁体和改写句。以第 3 例为例，删掉「有業道非業」的「有」再转换，比较究竟是在说某些业道，还是在说所有业道。第 9 例可以清除书页提供的上下文，自行判断「修淨非無漏」的定地以及这句话是否断言有实例。

程序用词表和句法把输入组装成带类型的逻辑树，从同一棵树生成公式、中文反译和 Lean 文件。页面会显示必要的解释选择。尚未覆盖的说法会显示卡在哪一步。你可以逐句批注并导出记录。[实现、适用范围与复核方法](docs/translate/README.md)

## 从第 46 步开始

王路《怎樣推導出一個毘曇命題？》（2022年7月）问「有覆無記色唯初靜慮繫」怎样推出。第 46 步判定有覆色是表，原文引前提 11 和第 43 步。色业分表、无表，已知某色不是无表，还须知道它属于色业。第 45 步恰好给出了这一点。对照该步的原文、形式化说明和实际传参即可检验。[第 46 步](https://wanglu2016.github.io/abhilib-gpt/#S46) · [完整组装](https://wanglu2016.github.io/abhilib-gpt/#T24)

项目保留16条前提、48个编号步骤、作者所附相关颂，以及三条证明路线。长证有47个步骤以 Lean 定理编码，第30步以表色子类型到色法的投影编码。三个分类前提 P04、P11、P14 由断类、色业、染性的定义承载。P05 支持第2–4步支线。其余12条在原次序的最终定理中以参数出现，此外还有5项明确标出的建模条件。阅读页面可切换简繁，作者原句和 Lean 代码始终保留原貌。

## 在本地复核

安装 [Lean / Elan](https://lean-lang.org/install/) 、Python 3 和 Node.js 18 或以上版本，进入仓库。项目锁定 Lean 4.19.0。命题译读工具没有第三方 JavaScript 依赖。

```sh
python3 tools/build.py --check
lake env lean tools/Transfer.lean
```

第一条命令编译证明，逐条检查所依赖的全局公理，核对编号和引用，从 Lean 导出112个候选模型描述及三张得心名册，并检查网页是否为同一份结果。第二条命令验证十个迁移小题。提交和拉取请求使用同一组命令。直接双击 `docs/index.html` 可离线阅读证明工作台。命题译读工具请使用下述说明中的本地 HTTP 入口。编辑条目后运行 `python3 tools/build.py` 重建页面。

## 如何扩展

1. 在 `AbhiLib/` 建立局部理论，分别定义对象、关系、经论立场与额外解释条件。用稳定编号组织自然语言与形式声明。
2. 给命题写出 Lean 证明，或给出满足背景而违反结论的模型。能做到两者中的哪一步，就登记到哪一步。
3. 将新模块导入 `AbhiLib.lean`，在 `data/entries.tsv` 登记声明、出处和解释范围，相关术语写入 `data/concepts.tsv`。分类、定义、推导、文本归属分别审核。操作细节见 [维护约定](AGENTS.md)。

当前模型压缩了无色四地，并单列不系。五项桥接是这版编码所需的解释条件，尤其第32步如何把「同染」细分到「同为有覆」，以及亲发心的适用范围，均待义理审读。四条简化规则各自有删除反例，只说明该固定小模型中的不可删性。全文献的最小前提集仍待研究。

原文与著作署名王路。引文及相关电子版分别循原出处的使用条款。原学习项目、书籍与颂文入口见 [阿毗达磨学习库](https://github.com/wanglu2016/abhidharma)。
